# Problem

![](https://assets.leetcode.com/uploads/2022/02/02/ex1-1.png)

給你一個 linked-list 每個節點有一個整數，裡面有節點數字 `0` 隔開(如上圖)，對於每個 `0` 圍起來的區間，可以相加合併起來成為一個節點，問你能不能合併完所有區間，然後回傳

## 測資限制

- $3 \le n \le 2\cdot 10^5$
- $0 \le val \le 1000$
